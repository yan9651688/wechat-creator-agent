# 语料

- `改稿对照/samples/`：每篇三件套 `日期-主题-0-AI初稿.md`、`-1-人工改稿.md`、可选 `-2-检测记录.md`。初稿必须存改前原样。
- `改稿对照/改稿规则.md`：攒 3～5 篇后，让 Claude 逐段 diff，把你的改法归类写在这里，每条标注来源样本日期，过期好回收。
- `范文/`：你自己最满意的旧文 3～5 篇。

飞轮：捕获 → 蒸馏（每 3～5 篇）→ 应用（AI 写完先按规则自改，再给你）→ 验证（对比你的改法，差距就是下一轮蒸馏重点）。

学习前先记清楚修改人、版本状态、文体和来源文件，不从「自改稿」「定稿」的文件名猜是谁改的。

| 对照情况 | 可以用来了解什么 |
| --- | --- |
| 作者确实改了字 | 结合上下文学作者改了哪些词、句子或判断 |
| 只重新分段 | 了解段落节奏，不当作措辞偏好证据 |
| 作者确认，内容未变 | 了解可接受的成稿，不算新增人工改字对 |
| AI 自改，尚未确认 | 记录工作过程，不据此推断作者偏好 |

只学表达不搬运事实。旧文章里的收入、经历、客户反馈和情绪，不自动成为下一篇的事实。单个样本里的改法先记下，反复出现且文体相近时再归纳；用户的新要求可以推翻旧归纳。
