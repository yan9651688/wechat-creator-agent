# 形象与封面

（模板：如果你有固定的 IP 形象，把它的长相、配色、禁忌写在这里，并把参考图放进 `素材/IP/`。没有 IP 的话，这页只用来定封面规格和风格。）

## 参考图怎么用（有 IP 形象才需要）

| 文件 | 用途 |
|------|------|
| `素材/IP/身份参考.*` | 长相以它为准 |
| `素材/IP/风格参考.*` | 只参考动作和笔触，不照搬里面的构图 |
| `素材/IP/头像.jpg` | 小红书卡片角标 |
| `素材/IP/角色与画风说明.txt` | 几句话的长相和禁忌，`工具/生图.sh` 会自动拼进提示词 |

## 必须保留的长相（自己填）

- `<角色的 3～5 个不能变的识别点：外形、配色、服装、道具>`
- 气质：`<一句话>`

## 不能出现的

- `<例如：3D 塑料感、写实动物、水印、乱码文字、随机 logo、假的后台截图和假检测分数>`
- 插画只解释流程，不能当操作证据。

## 配色

选一到两套，一篇文章只用一套，别混：`<例如：红白编辑风 / 暖黄手绘 / 蓝紫科技>`。

## 尺寸

| 用在哪 | 比例 | 说明 |
|--------|------|------|
| 公众号头条封面 | 2.35:1（如 1880×800） | 标题和主体分左右两区；再检查 1:1 居中裁剪时主体还在 |
| 公众号次条 / 分享卡 | 1:1 | 单独出一张，或从宽图里裁，裁完要检查 |
| 小红书 | 3:4（1242×1660） | 见 `06-小红书.md` |

## 封面文字

- 只放一个主标题和一个副标题，手机缩略图里能看清。
- 主体不挡字，四边留安全距离。
- 出图后**逐字核对**。模型写错字就让它针对那几个字改一次；还不对，就出一张不带字的底图，后期用程序叠字。
- 不在封面上放没有核实过的收入和时间承诺。

## 用 Codex CLI 生图

```bash
./工具/生图.sh 输出文件.png "画面描述……"
```

脚本把 `素材/IP/` 里的参考图交给 `codex exec` 调用 `image_gen`，生成后拷到你指定的路径，并在本篇目录的 `提示词/` 里记下提示词和原始路径。提示词写法：

1. 先写画面任务：这张图在文章里负责什么（封面、开场、关键判断）。
2. 再写画面里有什么、在干什么。一张图只突出一个动作。
3. 写配色和比例。
4. 写要出现的标题文字（逐字），或者写「画面中不要出现任何文字」。
5. 有 IP 的话最后重复一遍长相要点。

## 画风提示词怎么写

做漫画号、给文章换画风时，画风那一段提示词决定了整组图的味道。几条从实测里来的做法：

- **形容词要翻成看得见的东西**。「松散」「温柔」「高级」「反精致」模型看不懂，常见结果是画成干净的矢量图、建筑效果图或标准 Q 版。要写成线条怎么抖（粗细不匀、断笔、重复描）、颜色涂到哪（只涂哪一样、故意没涂满、涂出线外）、人占画面多大、脸画到几分（「眼睛两个小黑点、嘴一道短横线、没有皱纹」），再写一句「绝不能像矢量图 / 效果图 / 儿童绘本」堵住最常见的跑偏。
- **先小样再定稿**。每种画风拿两个不同场景各画一张，同一批跑完放在一起看：味道对不对、主体是不是太小、表情有没有跑偏（讽刺画成恐怖片、冷淡画成写实）。只改出问题的那几张，第二轮对比着看。第一轮和第二轮的对比图本身就是好素材。
- **隐喻类画风先想隐喻**。一根线、概念漫画这类画风，画面那一行要写「什么东西变成了什么东西」，写得太绕模型就照实画一个普通场景。
- **不写画家名字**。只写看得见的线条、颜色和构图，参考了谁记在事实底稿里，不进提示词也不进正文。
- **图里不出字**。中文字模型容易写错，对白和标题留白，后期程序叠字。
- **给读者的提示词要能直接复制**：画风段落原样放出，最后一行留成 `画面：【……】`，括号里写清要填什么。多种画风可以合成一段合集，开头说明「只用本次画风那一段」，结尾留「本次画风」「本次画面」两行；合集发出去前自己拿它跑一张，确认模型选对了画风。

## 系列图提示词：一组好几张怎么不翻车

一个故事、一套漫画要分 4 到 6 张画时，单张都对、放一起就穿帮。一次连画 9 组、54 张的实测里，第一次就能用的 44 张，重画的 10 张毛病都出在下面三处，画系列图前先对着把提示词写满：

1. **人物从头到脚写全，颜色写死**。头上、上身、下身、鞋、随身东西，一样不漏。没写的那一样模型每张自己猜：写了上衣没写裤子，六张裤子颜色各不一样；写了风衣没写下装，前四张牛仔裤，后两张变成裙子。
2. **故事里东西变了，在那一张单独说**。题材段写了「每张都是这身打扮」，模型就每张都照画。角色变成了动物，那张要写「画面里不要出现原来那个人」；东西丢了，要写「腰上什么都不挂」。只写「空剑鞘」还会画出剑柄，要写到什么都没有。
3. **关键线索写成量得出来的样子**。「蒙满白雾的眼镜」照样画成透亮的；写成「镜片完全被白雾糊满，看不见眼睛」，再加一句「两副眼镜的差别必须一眼就看出来」才对。「一层套一层」画成一张长桌；写死「三层、越往上越小」才对。几层、多大、看不看得见，不写感觉。
4. **比喻它会当真**。写猫「像国王」，它真给猫戴王冠、披披风。想要就留着，不想要就写「不要王冠和衣服」。

题材段模板（也适合原样放进文章给读者）：

```
题材：【故事名 / 主题】，【朝代或年代】。
主角：【发型 + 头上戴的】，【上衣款式和颜色】，【下装款式和颜色】，【鞋】，【随身带的东西】，每张都是这身打扮。
配角：同上，一个一个写。
不能出现的东西：【那个年代没有的东西】，画面里不要任何文字。

画面：【谁 + 在干什么】。
（这一张里有东西变了，单独写一句。）
（这一张的关键线索写成能看出来的样子，最后加一句「这个差别必须一眼就看出来」。）
```

出完一组，几张并排逐张看：衣服颜色一致吗，变了的东西还有没有残留，线索一眼看不看得出来。只重画不对的那一张，改了哪句、画了几轮记在 `提示词/`（如 `第二轮/`、`第三轮-x.txt`），重画前后拼一张对比图留着。攒够一批，这些重画记录本身就能写一篇回顾。

## 封面排字和拼图

- 背景和主体让模型画，标题文字和真实界面截图用浏览器排：写一个固定宽高的 HTML（1880×800 或 1080×1080），底图做背景，截图、成品小图、标题按位置放好，用无头 Chrome 截图。字不会错，截图也是真的。
- 从宽图做 1:1 时，空出来的地方用底图里的纸纹铺满，接缝处用渐变遮罩过渡，不要直接补纯色，纯色会露出一道接缝。
- 不想开浏览器时也可以用 PIL 合成：底图按高缩放放右边，左缘一段渐变融进底色，左侧排两三行标题和几张正文缩略图；1:1 从底图里裁正方形，不重新排字。合成完照样逐字核对。
- 主体放在 2.35:1 裁切的安全带里，头顶和边缘留出空间；拼完看一眼有没有被裁掉耳朵、头顶。

## 一篇文章里 IP 出现几次

封面默认有，正文里最多再一到两次。我说某一篇封面不放 IP，只管那一篇。流程、对比、数据、真实界面优先用截图和说明图。删掉这张图读者也不少理解什么，那就删。

## 交付前检查

1. 形象还是同一个吗？（有 IP 才查）
2. 笔触和气质还在吗？
3. 比例对不对，主体有没有压到标题？
4. 文字逐字对过了吗？有没有乱码、水印、多余的人？
5. 标着「实际操作」的地方，另外有真实截图或日志吗？
